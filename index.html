Employee Task Management System

Daily task tracking with automatic reset

Project Overview

This system allows employees to log in with their employee code and view their daily tasks. As they complete tasks, they can mark them as done. At midnight, the system automatically resets all tasks for the next workday.

Key Features

  • Employee authentication with unique codes
  • Task completion tracking with timestamps
  • Automatic daily task reset
  • Admin dashboard for task management
  • Real-time updates without page refresh
